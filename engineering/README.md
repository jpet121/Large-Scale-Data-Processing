# PEHAVOS / ABVOS engineering artifacts

These are the source-backed engineering and assurance artifacts from the original handoff and corrected implementation release. They are included for review and traceability; the source application is in the repository root.

- `core_docs/`: 15 project/architecture/implementation/verification documents.
- `companion/`: 7 supporting assurance artifacts.
- `codex/`: implementation tasks, coverage-first policy and development handoff.
- `analysis/`: engineering and auditor reviews.
- `evidence/requirement_trace.json`: recorded traceability.
- `source/REQUIREMENT_INDEX.json`: compiled requirement index.

The authoritative requirements remain `Project Requirements.MD` and `source/contract.xml` at the repository root. See the latest `verification/` reports for subsequent scale-test results; original design files are historical planning artifacts.
